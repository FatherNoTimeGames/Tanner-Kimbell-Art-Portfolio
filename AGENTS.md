# Project rules

- This repository is exclusively Tanner Kimbell’s art portfolio. Preserve existing artwork, unrelated changes, and established decisions. Work incrementally; obtain approval before major restructuring, settings changes, or deployment.
- Publish only `docs/`. Keep the website buildless with plain HTML/CSS/JS, no paid services, and minimal dependencies. Preserve accessible Android and desktop navigation.
- Display only supplied artwork explicitly approved for portfolio publication. Never generate or substitute portfolio images. Never overwrite original artwork without permission.
- All painting-challenge activity takes place in the chat: assignments, authentic photographic references, submissions, critiques, revisions, acknowledgment, summaries, and progress. Do not add challenge pages, records, data, navigation, or tracking functions to this site or repository. Do not create a separate challenge repository.
- A finished challenge painting may appear in the portfolio only after explicit portfolio approval, through the same process as any other painting.
- This repository is public. Do not commit private notes, unpublished artwork, or internal conversations. Exclusion from Pages does not make repository files private.
- Leave the existing challenge automation unchanged unless the user explicitly authorizes a change.
- Maintain focused commits on the development branch. Hosting remains pending separate approval; do not merge, change settings, or deploy automatically.
